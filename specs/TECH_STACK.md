# Tech Stack

## Runtime

- [TypeScript](https://www.npmjs.com/package/typescript)

## CLI

- [`commander`](https://www.npmjs.com/package/commander) for command line parsing
- [`@clack/prompts`](https://www.npmjs.com/package/@clack/prompts) for interactive prompts

## Configuration

- [`cosmiconfig`](https://www.npmjs.com/package/cosmiconfig) for config discovery
- [`zod`](https://www.npmjs.com/package/zod) for config validation

## Process Execution

- [`execa`](https://www.npmjs.com/package/execa) for shell commands

## Terminal Output

- [`picocolors`](https://www.npmjs.com/package/picocolors) for colorizing output
- [`ora`](https://www.npmjs.com/package/ora) for terminal spinners
